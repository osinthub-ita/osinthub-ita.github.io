# OSINTHUB-ITA
Catalogo italiano di risorse e strumenti OSINT (Open Source Intelligence).
- Avvio con scelta modalità accesso (Ospite / Utente / Admin) e terminale Matrix fosforo verde.
- Pannello Utente (user.html) con strumenti salvati, note operative e stato segnalazioni.
- Pannello Amministratore (admin.html) protetto con hash SHA-256, statistiche e gestione utenti.
- Gestione cookie a norma del Garante Privacy italiano e GDPR.
